# 02 - SecCM Phases

## Four Phases

1. **Planning**
   - Policy/procedures
   - SecCM plan
   - CCB setup
   - inventory strategy
   - tool and training planning

2. **Identifying and Implementing Configurations**
   - establish secure configurations
   - test for functional/security impact
   - document deviations
   - approve/deploy baseline

3. **Controlling Configuration Changes**
   - formal change request workflow
   - security impact analysis
   - CCB approval
   - implementation + verification + closure

4. **Monitoring**
   - detect baseline drift
   - detect unauthorized components/changes
   - report status, metrics, and remediation actions

## Exam Memory Hook
- **Plan -> Baseline -> Change -> Monitor**

## Common Exam Trap
- Treating monitoring as optional. In NIST view, monitoring is continuous and loops back to earlier phases.

Source: [NISTSP800128.pdf](NISTSP800128.pdf)
