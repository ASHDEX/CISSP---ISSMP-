# 03 - Roles and Governance

## Key Roles
- **CIO:** executive direction and approval of organizational program direction.
- **SAISO/CISO equivalent:** security leadership and specialist support.
- **Authorizing Official (AO):** accepts/rejects risk for significant changes.
- **System Owner:** accountable for implementing SecCM at system level.
- **SSO:** operational security oversight, monitoring, and analysis support.
- **System Administrator/Developers:** implement approved changes and secure settings.
- **System User:** initiates requests and supports functional validation.

## Configuration Control Board (CCB)
- Multi-perspective governance body.
- Reviews, approves, defers, or rejects changes.
- Ensures separation of duties (requestor ≠ sole approver).
- Should maintain records (minutes, rationale, approvals, actions).

## ISSMP Takeaway
- Governance quality is measured by **decision rights, accountability, and evidence trail**.
